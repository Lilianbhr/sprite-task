# sprite-task
Little week-end project with python and pygame.

## Le Projet : "Mood-Based Task Flow"
Au lieu d'une simple liste de tâches (To-Do list) classique, l'application propose des tâches à l'utilisateur en fonction de son énergie du moment.

## Cahier des charges (Superficiel)
 - L'interface "État d'esprit" : Au lancement, l'utilisateur choisit son niveau d'énergie.
 - Le sélecteur intelligent : L'app affiche uniquement les tâches qui correspondent à cet état d'esprit.
 - Le Timer "Focus" : Une fois la tâche lancée, un compte à rebours s'enclenche.
 - Récompense visuelle : Si la tâche est terminée avant la fin du timer, l'utilisateur gagne un petit badge ou voit une barre de progression évoluer de façon satisfaisante.

## Pistes d'extensions
 - Ajouter un mode "Urgence" qui ignore l'énergie.
 - Intégrer une petite musique d'ambiance Lo-Fi qui change selon l'état d'esprit choisi.
 - Faire en sorte que l'application "félicite" l'utilisateur avec une phrase aléatoire un peu drôle.
